## ✌️ preview

Check out the live demo by clicking [here](https://dashkit-lite.cssninja.io/). 
Dashkit is built with [Bulma](https://bulma.io) and [Alpine JS](https://github.com/alpinejs/alpine).

## 👍 Features

* Gulp 4 and nodejs 16.x (minimum)
* Bulma 0.9.x
* ES6 support
* Alpine v3.x

## 👌 Usage

1. Install Dev Depedencies

```sh
pnpm i
```

2. To start development server

```sh
pnpm dev
```

3. To build the project

```sh
pnpm build
```
